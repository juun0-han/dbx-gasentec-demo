# Ask Genie 데모 질문

Genie Space 또는 AI/BI Dashboard의 Ask Genie에서 질문을 실행합니다.

## 기본 운영 질문

```text
전체 기간의 총 send-out은 얼마야?
```

```text
터미널별 평균 가동률을 비교해줘
```

```text
월별 send-out 추이를 보여줘
```

## 운영·O&M 질문

```text
설비 유형별 다운타임과 유지보수 비용을 비교해줘
```

```text
BOG 비율이 높은 상위 3개 설비를 보여줘
```

```text
ALARM 상태 기록과 사고 건수를 알려줘
```

## 다의어 질문

```text
성능이 좋은 터미널을 알려줘
```

기대 동작:

```text
send-out, average uptime, BOG rate, downtime, maintenance cost 중 어떤 기준으로 성능을 볼지 확인한다.
```

## 대시보드 연계 질문

```text
현재 대시보드에서 평균 가동률이 가장 낮은 터미널의 다운타임과 유지보수 비용을 보여줘.
```

```text
BOG rate가 높은 설비를 확인하고 관련 O&M 점검 항목을 설명해줘.
```
